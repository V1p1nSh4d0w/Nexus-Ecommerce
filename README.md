# NEXUS — Premium E-Commerce Website

> BCA 6th Semester Major Project | Frontend Web Development

A fully functional, responsive e-commerce web application built using **HTML5**, **CSS3**, and **Vanilla JavaScript** — no frameworks, no backend required.

## ✨ Features

- **Multi-page SPA** — Home, Products, Categories, Deals, Blog, About, Contact
- **Product Catalog** — 24+ products with search, sort & filter by category
- **Shopping Cart** — Add/remove items, quantity control, cart drawer
- **Wishlist** — Save favourite products
- **Checkout Flow** — 3-step checkout with Shipping → Payment → Review
- **Payment Methods** — Credit/Debit Card, UPI (GPay, PhonePe, Paytm, BHIM), Net Banking, Wallets, COD
- **Order Tracking** — Enter order ID to see live delivery status timeline
- **User Auth** — Sign In / Sign Up / Profile / Order History
- **Flash Sale** — Live countdown timer for flash deals
- **Promo Codes** — Coupon code system at checkout
- **Product Comparison** — Side-by-side product comparison table
- **Responsive Design** — Mobile-first, works on all screen sizes
- **Dark Theme** — Premium dark UI with purple gradient accents

## 🚀 How to Run

### Option 1 — GitHub Pages (Recommended)
Visit the live demo link above.

### Option 2 — Run Locally
```bash
# Clone the repository
git clone https://github.com/yourusername/nexus-ecommerce.git

# Open in browser
cd nexus-ecommerce
open index.html   # macOS
# OR
start index.html  # Windows
```

No Node.js, no npm, no build tools required — just open `index.html` in any browser.
